# 🎬 FILM BRO'S

A modern movie browsing web application built with **React**. Film Bro's allows users to explore movies through a visually engaging interface inspired by popular streaming platforms.

## 🚀 Live Demo

🔗 **Live Website:** https://anishprasad-26.github.io/FILM-BROS-/

---

## 📌 About The Project

**Film Bro's** is a React-based movie browsing project created to practice and demonstrate modern frontend development concepts.

The project focuses on building a dynamic and visually appealing movie interface using reusable React components, API integration, and client-side routing.

---

## ✨ Features

* 🎥 Browse and explore movies
* 🔥 Dynamic movie content fetched using the **TMDB API**
* 🖼️ Movie posters and visual content
* 📄 Dedicated movie details page
* 🔀 Client-side navigation using React Router
* 🧩 Reusable React components
* 📱 Responsive and modern user interface
* ⬅️➡️ Scrollable movie rows with navigation controls
* 🎨 Custom styling inspired by modern streaming platforms
* 🌐 Deployed using GitHub Pages

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

Go to the project folder:

```bash
cd YOUR-REPOSITORY
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 🔑 API

This project uses data from **The Movie Database (TMDB) API**.

To run the project locally, create a `.env` file and add your TMDB API key.

Example:

```env
VITE_TMDB_API_KEY=your_api_key_here
```

> ⚠️ Never upload your API key to a public repository.
